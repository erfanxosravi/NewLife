# زندگینامه (Zendegi-Nameh)

شبیه‌ساز متنی زندگی ایرانی از تولد تا پایان عمر؛ کاملاً آفلاین، راست‌به‌چپ (RTL) و داده‌محور.

## اجرا و تست

```bash
npm install
npm run dev           # اجرای سرور توسعه روی پورت 3000 (مسیر /styleguide برای مشاهده کامپوننت‌ها)
npm run validate:data # اعتبارسنجی تمام فایل‌های JSON با Zod
npm test              # اجرای تست‌های واحد و شبیه‌سازی ۱۰۰۰ زندگی
npm run build         # اعتبارسنجی داده‌ها + بیلد نسخه PWA
```

## مجوزهای کتابخانه‌های متن‌باز و منابع داده‌ای

- **Lucide Icons (`lucide-react`)**: تحت مجوز **ISC License** (آیکون‌های خطی متن‌باز، تنظیم‌شده با `strokeWidth={1.75}`).
- **Vazirmatn Font**: تحت مجوز **SIL Open Font License (OFL 1.1)**.
- **jalaali-js**: تحت مجوز **MIT License**.
- **Vector Country Flags (`src/ui/components/flags/CountryFlag.tsx`)**: آیکون‌های برداری SVG اختصاصی و بسته‌بندی‌شده برای نمایش پرچم کشورها (ایران، ترکیه، آلمان، امارات، بریتانیا، کانادا و الگوی عمومی) جهت اطمینان از رندر یکسان در تمام سیستم‌عامل‌ها بدون اتکا به ایموجی؛ منتشرشده تحت مجوز **MIT License**.

## داده‌های اقتصاد کلان و چندارزی (`src/data/countries_macro.json`)

- تمام نرخ‌های مرجع مالی، دستمزد حداقل، تورم، مالیات و ضرایب نرخ ارز در `countries_macro.json` دارای فیلدهای `source`، `asOf` و `confidence` (`verified` یا `estimate`) هستند.
- مقادیر مرجع سال ۲۰۲۵–۲۰۲۶ (از جمله حداقل دستمزد ساعت/ماه در ترکیه، آلمان و بریتانیا و نرخ‌های پایه تورم و ارز) در زمان بیلد به صورت محلی بارگذاری می‌شوند و هیچ فراخوانی شبکه‌ای در زمان اجرا انجام نمی‌گیرد.
- پیش‌بینی‌های پس از سال ۱۴۰۵ تماماً شبیه‌سازی قطعی مبتنی بر بذر زندگی (`worldSeed`) هستند.
